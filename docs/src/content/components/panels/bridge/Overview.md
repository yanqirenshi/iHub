# Overview

ポンチ絵 (なんでもありの概念図) を、@yanqirenshi/d3.unchi で、パネル一杯に描きます。
艦橋 (`/`) の「Overview」タブのパネルです。

- ソース: `packages/ihub.core/src/components/panels/bridge/components/Overview.js`

図のデータは、API サーバーから読み込んだ次のコレクションです。([Overview のデータ](#/diagrams))

| ファイル | 内容 |
|---|---|
| `data/overview/nodes.json` | ノード (入れ子にできます) |
| `data/overview/edges.json` | ノードの間の線 |

図では、次のことができます。

1. ノードをドラッグすると、動かした位置を `overview/nodes` に保存します。
2. ノードや線を Ctrl + クリック (Mac は ⌘ + クリック) すると、右端にインスペクタ (幅 `320px`) を出します。(0.11.0 以降。0.10.x までは、右クリックでした)
3. インスペクタで項目を書き換えて「適用」を押すと、`PATCH /api/overview/{nodes|edges}/{id}` で保存します。
4. 保存できなかったときや、値が正しくないときは、上にエラーを出します。
5. ドックの「要素の追加」の丸から、ノードを足せます。(0.12.0 以降。下の「ノードの追加」)

書き換えられる項目は、[図の編集](#/diagrams) の「Overview でサイズ・色・接続位置・ラベルを変える」にあります。
(0.12.0 で、ノードの項目に、文字の大きさ・文字の色・文字の太さ・角の丸み・影・背景の不透明度・説明・リンクの 8 つが増えました)
(0.12.1 で、線の項目に、線の種類 (`stroke.type`: `solid`・`dashed`・`dotted`) が増えました)
ほかの画面などでデータが変わったときは、図を作り直します。
見ている位置と拡大の度合いは、ブラウザ (`localStorage`) に覚えます。(図の code は `overview`)

## ノードの追加

0.12.0 以降の動きです。
このパネルを開いている間だけ、ドックの右端に「要素の追加」の丸 (+ のアイコン) が出ます。(丸が 4 つになります。ほかのタブ・ページでは 3 つです)
丸を押すと、吹き出しの中に、「ノードの追加」のフォームが出ます。
丸をもう一度押すと、閉じます。(「キャンセル」はありません)

見出しと名称 (必須) は、いつも上に出ます。
ほかの項目は、タブに分かれます。(項目は、全部で 15 個です)

| タブ | 項目 |
|---|---|
| 基本 | 幅 (既定 160)・高さ (既定 80) |
| 背景 | 背景色・背景の不透明度 (0〜1。1 で不透明) |
| 枠線 | 枠線の色・枠線の種類 (実線・破線・点線)・枠線の太さ・角の丸み・影 |
| 文字 | 文字の大きさ・文字の色・文字の太さ (標準・太字) |
| そのほか | 説明・リンク (`http://`・`https://` で始まる URL か、`/` で始まるパス) |

- 「作成」で、`POST /api/overview/nodes` に、最上位のノードを 1 件足します。(id は、API サーバーが振ります)
- 置く所は、いまある最上位のノードの右です。図で、ドラッグして動かせます。
- 足せたら、フォームは初めの値に戻り、足したことの知らせが出ます。吹き出しは開いたままです。(続けて足せます)
- 入れなかった項目は、レコードに書きません。(d3.unchi の既定で描きます)
- ただし、文字 (大きさ・色・太さ) は、どれか 1 つでも入れたら、`label.font` に 3 つとも書きます。(入れなかったものは、大きさ 16・色 `#333333`・太さ `normal`)
- 名称が空のとき・色でない文字・範囲の外の数を入れたときは、誤りが出て、保存しません。
- 足せるのは、ノード (箱) だけです。線・ほかの種類の要素は、ファイルで足します。削除も、ファイルで行います。
- 丸は、`useDockOperator` で足しています。([カスタマイズ](#/customize) の「タブを開いている間だけ、ドックに丸を足す」) このパネルをほかのページのタブに出したときも、そのタブを開いている間は、丸が出ます。

## import のしかた

```jsx
import { panels } from '@yanqirenshi/ihub.core';

// <panels.bridge.Overview/>
```

0.2.x までの名前 `panels.cockpit.Overview` も、同じ部品の別名として使えます。
(0.3.0 で `panels.bridge` に改めました。古い名前は、将来の minor で消すことがあるので、新しい名前に移しておくと安心です)

## props

props はありません。
(タブのあるページのパネルとして使うと、`tab` を受け取りますが、使いません)

## 使い方の例

ほかのページのタブに、同じ図を出します。([ページのタブとパネルを足す](#/customize))

```jsx
import { panels } from '@yanqirenshi/ihub.core';

const config = {
    // (省略)
    tabs:   { PAGE_DATA: { list: [{ code: 'overview', label: 'Overview' }] } },
    panels: { PAGE_DATA: { overview: panels.bridge.Overview } },
};
```

## 注意

- `<IHub>` の中で使ってください。
  API サーバーから読み込んだデータと、redux の store (RTK Query の `dataApi`) を使います。
- 覚えた位置の鍵には、設定の `app.name` を使います。(`ihub:{app.name}:view:overview`)
- 大きさは親の大きさ一杯 (`width: 100%`・`height: 100%`) です。
  親に高さを付けてください。
- 図は 1 つだけです。
  2 つの場所に出しても、同じ `data/overview/` を描き、覚える位置も同じです。
- データを手で書くときに、`label.font` を一部だけ (`color` なしで) 書くと、文字が白になり、見えません。
  `label.font` を書くときは、`color` も書いてください。([図の編集](#/diagrams) の「Overview のデータ」)
