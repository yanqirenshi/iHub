# ResearchQuestions

Systemic Design のツール「ResearchQuestions」の中身を描くための部品です。
今は中身がまだ無く、部品の名前 (`ResearchQuestions`) を文字で出すだけです。

- ソース: `packages/ihub.core/src/components/panels/systemic_design/ResearchQuestions.js`
- Systemic Design のページ (`pages.SystemicDesignContents`) が、URL の名前が `RESEARCH_QUESTIONS` のとき (`/systemic-design/RESEARCH_QUESTIONS`) に描きます。

## import のしかた

```jsx
// panels.systemic_design.ResearchQuestions
```

props はありません。
