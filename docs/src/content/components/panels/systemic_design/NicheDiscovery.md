# NicheDiscovery

Systemic Design のツール「NicheDiscovery」の中身を描くための部品です。
今は中身がまだ無く、部品の名前 (`NicheDiscovery`) を文字で出すだけです。

- ソース: `packages/ihub.core/src/components/panels/systemic_design/NicheDiscovery.js`
- Systemic Design のページ (`pages.SystemicDesignContents`) が、URL の名前が `NICHE_DISCOVERY` のとき (`/systemic-design/NICHE_DISCOVERY`) に描きます。

## import のしかた

```jsx
import { panels } from '@yanqirenshi/ihub.core';

// panels.systemic_design.NicheDiscovery
```

## props

props はありません。

