# RichContext

Systemic Design のツール「RichContext」の中身を描くための部品です。
今は中身がまだ無く、部品の名前 (`RichContext`) を文字で出すだけです。

- ソース: `packages/ihub.core/src/components/panels/systemic_design/RichContext.js`
- Systemic Design のページ (`pages.SystemicDesignContents`) が、URL の名前が `RICH_CONTEXT` のとき (`/systemic-design/RICH_CONTEXT`) に描きます。

## import のしかた

```jsx
import { panels } from '@yanqirenshi/ihub.core';

// panels.systemic_design.RichContext
```

## props

props はありません。

## 使い方の例

```jsx
<panels.systemic_design.RichContext/>
```
