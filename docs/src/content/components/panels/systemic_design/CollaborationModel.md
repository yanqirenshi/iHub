# CollaborationModel

Systemic Design のツール「CollaborationModel」の中身を描くための部品です。
今は中身がまだ無く、部品の名前 (`CollaborationModel`) を文字で出すだけです。

- ソース: `packages/ihub.core/src/components/panels/systemic_design/CollaborationModel.js`
- Systemic Design のページ (`pages.SystemicDesignContents`) が、URL の名前が `COLLABORATION_MODEL` のとき (`/systemic-design/COLLABORATION_MODEL`) に描きます。

## import のしかた

```jsx
import { panels } from '@yanqirenshi/ihub.core';

// panels.systemic_design.CollaborationModel
```

## props

props はありません。
