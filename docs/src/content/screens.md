# 画面の見方

## 画面の構成

| 場所 | 内容 |
|---|---|
| 左 | サイドメニューです。アイコンを押すと、そのページへ移ります。 |
| 下 | ドックです。3 つの丸いボタンが並びます。 |
| 真ん中 | ページの内容です。ページによっては、上にタブが並びます。 |

## サイドメニュー

サイドメニューは、ページ (iHub・Docs・Etc) ごとに項目をまとめています。

| ページ | 主な項目 |
|---|---|
| iHub | コックピット・市場・ビジネス・デザイン・画面・API・バッチ・データ・クラス・外部リソース・システム構成・メッセージ・*Ops・Scrum・組織・WBS・Help |
| Docs | ユーザーシナリオ・カスタマージャーニーマップ・ユースケース・Systemic Design・BPMN・UI Design・画面遷移図・Class図・機能一覧・TM・ER図・UML・PAD |
| Etc | System Dynamics・DDD・WBS・アカウント・認証・Next.js |

Docs のページは、モデリングの手法などの参考資料をまとめたページです。
設計のデータを図にしたものは、iHub のページ (データ・ビジネス・画面・システム構成) のタブにあります。

使わない項目は、非表示にできます。(下の「ドック」を見てください)

## ドック

画面の下にある 3 つのボタンです。
押すと、ボタンの上に吹き出しが開きます。

| ボタン | 内容 |
|---|---|
| X | 予備のボタンです。(今は、空の吹き出しが開きます) |
| GitHub のマーク | Issue を作って、GitHub の Project に追加します。([GitHub との連携](#/github)) |
| メニューのマーク (≡) | サイドメニューの項目の、表示と非表示を切り替えます。 |

### サイドメニューの項目を、表示・非表示にする

1. ドックのメニューのボタン (≡) を押します。
2. 吹き出しの上のタブで、ページ (iHub・Docs・Etc) を選びます。
3. 項目ごとのスイッチで、表示 (on) と非表示 (off) を切り替えます。

- 切り替えると、画面を読み直さずに、サイドメニューへすぐ反映されます。
- 切り替えた結果は、個人の設定として `data/local/account_menus.json` に保存されます。
- 個人の設定は git で共有しないので、ほかの人のサイドメニューは変わりません。
- 何も切り替えていない項目は、既定値 (`src/config/ACCOUNT_MENUS.js` の `active`) のとおりに表示されます。
