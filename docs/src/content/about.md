# iHub とは

iHub は、アプリの設計の情報をまとめて共有するための、ドキュメントサイトの仕組みです。
WBS・ER 図・TM (T 字形 ER)・画面遷移図・システム構成図などを、1 つのサイトで見られるようにします。

## 使い方のイメージ

iHub は、ライブラリとして読み込むのではなく、フォルダごとコピーして使います。
たとえば、あるアプリを作るときは、次のように使います。

1. アプリのリポジトリに、ドキュメントサイト用のフォルダを作ります。(例: `docs/`)
2. そのフォルダに、iHub のフォルダ構成をそのままコピーします。
3. `data/` フォルダのデータ (JSON) を、アプリに合わせてメンテナンスします。
4. データを git で commit・push して、チームで共有します。

```
my-app/                 # アプリのリポジトリ
├─ src/                 # アプリのコード
└─ docs/                # ドキュメントサイト (iHub をコピーしたもの)
    ├─ data/            # このアプリの設計データ
    ├─ src/             # 画面
    ├─ server/          # API サーバー
    └─ package.json
```

フォルダの名前は、`docs/` でなくてもかまいません。
コピーのしかたは、[導入のしかた](#/setup) を見てください。

## できること

- 設計のデータを、図や表で見られます。(ER 図・TM・画面遷移図・システム構成図・Systemic Design・WBS)
- 図のノードをドラッグして、配置を変えられます。動かした位置は `data/` に保存されます。
- 図の要素を右クリックして、その要素の中身を、右端のインスペクタで見られます。
- WBS のノードを、画面から追加できます。
- エディタや git で `data/` を変えると、開いている画面にすぐ反映されます。
- GitHub の Issue や Projects を見たり、Issue を追加したりできます。

## 仕組み

iHub は、画面 (React) と API サーバー (Node.js) でできています。

| 部分 | 役割 |
|---|---|
| 画面 | 起動したときに、API サーバーから全データを読み込んで表示します。 |
| API サーバー | `data/` の JSON を読み書きします。書き込む前に、フォーマットとルールを確かめます。 |
| `data/` | 設計のデータ (JSON) です。git で共有します。 |

`npm start` で、画面と API サーバーが一緒に起動します。
どちらも自分のパソコンの中だけで動き、ほかのパソコンからは使えません。
