# 図の編集

図のノードをドラッグすると、動かした位置が `data/` に保存されます。
次の 5 つの図で使えます。

| 図 | 開き方 | つかむところ | 保存先 |
|---|---|---|---|
| ER 図 | データ (`/data`) の「ER図」タブ | テーブル | `er/entities.json` の `position` |
| TM | ビジネス (`/business`) の「TM」タブ | エンティティの見出し (名前の部分) | `tm/entities.json` の `position` |
| 画面遷移図 | 画面 (`/screens`) の「画面遷移図」タブ | 画面のノード | `sitemap/nodes.json` の `position` |
| システム構成図 | システム構成 (`/system-environment`) の「システム構成図」タブ | ノード | `deployment/nodes.json` の `position` |
| Overview (ポンチ絵) | コックピット (`/`) の「Overview」タブ | ノード | `overview/nodes.json` の `position` |

## 要素の中身を見る (インスペクタ)

図の要素を右クリックすると、コンテンツエリアの右端に、その要素のインスペクタが開きます。
Overview (ポンチ絵) だけは、一部の項目をここから書き換えられます。(下の「Overview でサイズ・色・接続位置・ラベルを変える」)
ほかの図は見るだけです。(書き換えは `data/` の JSON で行います)

| 図 | 右クリックできる要素 | 「プロパティ」に出る項目 |
|---|---|---|
| ER 図 | テーブルの見出しの文字、カラムの文字 | 名称・コード・種類・データ型・説明・ID |
| TM | エンティティの見出し (枠と文字) | 名称 (論理名と物理名の組のときは、論理名・物理名)・種類・説明・ID |
| 画面遷移図 | 画面のノード | 名称・種類・URL・ID |
| システム構成図 | ノード、線 | 名称・種類・ID |
| Overview (ポンチ絵) | ノード、線 | ノード: 名称・種類・ID・幅・高さ・背景色・枠線の種類・枠線の色 / 線: ID・接続元のノード・接続元の位置・接続先のノード・接続先の位置・線の色・線の太さ・ラベル |

- インスペクタには、「プロパティ」と「JSON」の 2 つのタブがあります。
「プロパティ」は主な項目を読みやすく並べたもので、「JSON」は要素の元のデータをそのまま整形して出します。
- 要素が持っていない項目は、「プロパティ」には出ません。(例: 線には名称がありません)
- 左端をドラッグすると、幅を変えられます。(220px から 640px まで)
右上の ✕ で閉じます。
- 別の要素を右クリックすると、表示が切り替わります。
- 要素のないところ (図の背景や、テーブル・エンティティの枠の余白など) を右クリックしたときは、ブラウザの普通のメニューが開きます。
- 右クリックでは、位置は保存されません。

## Overview でサイズ・色・接続位置・ラベルを変える

Overview のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/overview/` に保存して、図に反映します。

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| ノード | 幅・高さ | `overview/nodes.json` の `size.w`・`size.h` | 1 以上の数 (整数に丸めます) |
| ノード | 背景色 | `overview/nodes.json` の `background.color` | 色 (`#ff0000`・`red`・`rgb(255, 0, 0)` など) |
| ノード | 枠線の種類 | `overview/nodes.json` の `border.type` | `solid` (実線)・`dashed` (破線)・`dotted` (点線) |
| ノード | 枠線の色 | `overview/nodes.json` の `border.color` | 色 (背景色と同じ) |
| 線 | 接続元の位置・接続先の位置 | `overview/edges.json` の `from.position`・`to.position` | 角度 (整数に丸め、0 から 359 にそろえます) |
| 線 | 線の色 | `overview/edges.json` の `stroke.color` | 色 (背景色と同じ) |
| 線 | 線の太さ | `overview/edges.json` の `stroke.width` | 0 より大きい数 |
| 線 | ラベル | `overview/edges.json` の `label.text` | 文字 (空にすると、ラベルを消します) |

- 背景色・枠線・線の色・線の太さは、データに書いていないときも、図に描いている値 (既定の値) を出します。
保存するのは、変えた項目だけです。
- 線のラベルは、線の真ん中に描きます。
ラベルの文字の大きさや色 (`label.font`) は、`data/` の JSON で変えます。
- 接続位置の角度は、ノードの中心から見た向きです。
0 が真下で、時計回りに 90 が左、180 が真上、270 が右です。
- サイズ・背景色・枠線・線の色・線の太さを変えたときは、図を描き直します。
このときも、図全体の表示の位置や拡大の度合いは、そのままにします。
- 接続位置とラベルだけを変えたときは、描き直さずに線だけを動かします。
- 子のノード (`children` の中のノード) も、同じように変えられます。
- 値がおかしいとき (数でない、幅や高さが 1 より小さい、色として読めない、枠線の種類が 3 つのどれでもない、線の太さが 0 以下) や、保存できなかったときは、図の上にエラーを表示します。

## 位置の保存のきまり

- 位置は、整数に丸めて保存します。
- 図全体を動かしたり、拡大・縮小したりする操作は、保存しません。
- 保存できなかったときは、図の上にエラーを表示します。(API サーバーが止まっているときなど)

## 入れ子のノード (システム構成図・Overview)

システム構成図と Overview のノードは、`children` で入れ子にできます。

- 親のノードを動かすと、子のノードも一緒に動きます。
保存されるのは親の位置だけで、子の位置 (親の中での位置) は変わりません。
- 子のノードだけを動かすと、子の位置 (親の中での位置) が保存されます。

## ノードのリンク (システム構成図)

システム構成図のノードには、`link` でリンクを付けられます。
ノードの左下に「link」と出て、押すと `url` を新しいタブで開きます。
ノードに当たるフォルダ (Box や GitHub など) を開けるようにするときに使います。

```json
{
    "id": 4,
    "type": "COMPONENT",
    "label": { "text": "COMP 01" },
    "size": { "w": 200, "h": 100 },
    "position": { "x": 50, "y": 50 },
    "link": { "url": "https://example.com/" },
    "children": []
}
```

## Overview のデータ

Overview は、@yanqirenshi/d3.unchi で描くポンチ絵 (なんでもありの概念図) です。
`overview/nodes.json` と `overview/edges.json` には、d3.unchi の入力データの形のまま書けます。
(文字だけのノード・矢羽・円筒・画像など。書き方は d3.unchi の README を見てください)

- スキーマで検査するのは、`id`・`type`・`_class`・`size`・`position`・`children` と、線の端点・マーカーです。
見た目の項目 (`label`・`border`・`background` など) は検査しません。
- `id` には、数のほかに文字列も使えます。
子のノードも含めて、ほかのノードと重ならないようにします。

## ほかで変わったとき

ほかのタブ・エディタ・git でデータが変わったときは、図を描き直します。
このとき、図全体の表示の位置や拡大の度合いは、初めの状態に戻ります。
自分のドラッグで保存したときは、描き直しません。

## ノードや線を増やすとき

画面からできるのは、位置の変更と、Overview のサイズ・色・枠線・接続位置・線のラベルの変更だけです。
ノード・線・カラムなどを増やすときは、`data/` の JSON を書き換えます。
書き換えると、開いている画面にすぐ反映されます。
書き方は、[データの管理](#/data) と、`server/schemas/` のスキーマを見てください。
