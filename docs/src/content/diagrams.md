# 図の編集

図のノードをドラッグすると、動かした位置が `data/` に保存されます。
次の 5 つの図で使えます。

| 図 | 開き方 | つかむところ | 保存先 |
|---|---|---|---|
| ER 図 | データ (`/data`) の「ER図」タブ | テーブル | `er/entities.json` の `position` |
| TM | ビジネス (`/business`) の「TM」タブ | エンティティの見出し (名前の部分) | `tm/entities.json` の `position` |
| 画面遷移図 | 画面 (`/screens`) の「画面遷移図」タブ | 画面のノード | `sitemap/nodes.json` の `position` |
| システム構成図 | システム構成 (`/system-environment`) の「システム構成図」タブ | ノード | `deployment/nodes.json` の `position` |
| Overview (ポンチ絵) | コックピット (`/`) の「Overview」タブ | ノード | `overview/nodes.json` の `position` |

## 要素の中身を見る (インスペクタ)

図の要素を右クリックすると、コンテンツエリアの右端に、その要素のインスペクタが開きます。
どの図も、項目をここから書き換えられます。(下の「ER 図で名前・幅を変える」「TM で名前・種別・結線の記号を変える」「画面遷移図で名称・URL・色を変える」「システム構成図で名称・種類・色・矢印を変える」「Overview でサイズ・色・接続位置・ラベルを変える」)
TM の結線 (線) だけは、右クリックではなくクリックで開きます。

| 図 | 右クリックできる要素 | 「プロパティ」に出る項目 |
|---|---|---|
| ER 図 | テーブルの見出しの文字、カラムの文字 | 見出し (テーブル): 名称・コード・スキーマ・ID・説明・幅・高さ / カラム (識別子・属性のマスタ): 論理名・物理名・データ型・説明・ID |
| TM | エンティティの見出し (枠と文字)、識別子・属性の行、結線 (クリック) | エンティティ: 名称 (論理名と物理名の組のときは、論理名・物理名)・種別・ID・説明・幅・高さ / 行 (識別子・属性のマスタ): 名称・説明・ID / 結線: ID・種類・ラベル・接続元 / 接続先のエンティティ・位置 (角度)・カーディナリティ・オプショナリティ・サブセットの区分・区分コード・垂下する表・説明 |
| 画面遷移図 | 画面のノード (線は開けません) | 名称・種類・URL・ID・幅・高さ・背景色・枠線の色・枠線の太さ |
| システム構成図 | ノード、線 | ノード: 名称・種類・ID・説明・URL・幅・高さ・背景色・枠線の色・枠線の太さ / 線: ID・接続元のノード・接続元の位置・接続先のノード・接続先の位置・線の色・線の太さ・終点の矢印 |
| Overview (ポンチ絵) | ノード、線 | ノード: 名称・ID・幅・高さ・背景色・枠線の種類・枠線の色・枠線の太さ / 線: ID・接続元のノード・接続元の位置・接続先のノード・接続先の位置・始点のマーカー・終点のマーカー・線の色・線の太さ・ラベル |

- インスペクタには、「プロパティ」と「JSON」の 2 つのタブがあります。
「プロパティ」は主な項目を読みやすく並べたもので、「JSON」は要素の元のデータをそのまま整形して出します。
- 要素が持っていない項目は、「プロパティ」には出ません。(例: 線には名称がありません)
- 左端をドラッグすると、幅を変えられます。(220px から 640px まで)
右上の ✕ で閉じます。
- 別の要素を右クリックすると、表示が切り替わります。
- 要素のないところ (図の背景や、テーブル・エンティティの枠の余白など) を右クリックしたときは、ブラウザの普通のメニューが開きます。
- 右クリックでは、位置は保存されません。

## ER 図で名前・幅を変える

ER 図のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/er/` に保存して、図を描き直します。
項目の一覧と、入れられる値の検査は、@yanqirenshi/model.er (ER 図の図ごとの知識をまとめたパッケージ) が決めます。

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| テーブル | 名称 | `er/entities.json` の `name` | 文字 (空にはできません) |
| テーブル | コード・説明 | `er/entities.json` の `code`・`description` | 文字 (空にすると、項目を消します) |
| テーブル | 幅・高さ | `er/entities.json` の `size.w`・`size.h` | 0 以上の数 (整数に丸めます。0 で内容に合わせます) |
| カラム | 論理名 | `er/identifiers.json` か `er/attributes.json` の `name.logical` | 文字 (空にはできません) |
| カラム | 物理名・データ型・説明 | 同じファイルの `name.physical`・`data_type`・`description` | 文字 (空にすると、項目を消します) |

- カラムを右クリックしたときに出るのは、そのカラムが参照している識別子・属性のマスタです。
同じマスタを参照しているほかのテーブルのカラムにも、変更が反映されます。
- 関係 (線) は右クリックできません。(`data/` の JSON で変えます)
- 幅 (`size.w`) は、いまの d3.er では図に反映されません。(d3.er が内容に合わせて幅を決めます)
- 値がおかしいとき (数でない、幅や高さが 0 より小さい、名称が空) や、保存できなかったときは、図の上にエラーを表示します。

## TM で名前・種別・結線の記号を変える

TM のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/tm/` に保存して、図を描き直します。
項目の一覧と、入れられる値の検査は、@yanqirenshi/model.tm (TM の図ごとの知識をまとめたパッケージ) が決めます。
エンティティの種別ごとの色とバッジ、結線の角度の既定も、model.tm のものです。(d3.ter も同じものを読みます)

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| エンティティ | 名称 (または論理名) | `tm/entities.json` の `name` (または `name.logical`) | 文字 (空にはできません) |
| エンティティ | 物理名・説明 | `tm/entities.json` の `name.physical`・`description` | 文字 (空にすると、項目を消します) |
| エンティティ | 種別 | `tm/entities.json` の `type` | `RESOURCE`・`RESOURCE-SUBSET`・`EVENT`・`EVENT-SUBSET`・`COMPARATIVE`・`CORRESPONDENCE`・`RECURSION`・`MANY-VALUED-OR`・`MANY-VALUED-AND`・`CLASS` |
| エンティティ | 幅・高さ | `tm/entities.json` の `size.w`・`size.h` | 0 以上の数 (整数に丸めます。0 で内容に合わせます) |
| 識別子・属性の行 | 名称 (または論理名)・物理名・説明 | `tm/identifiers.json` か `tm/attributes.json` の `name`・`description` | 名称は空にできません。物理名・説明は、空にすると項目を消します |
| 結線 | 種類・ラベル・説明 | `tm/relationships.json` の `type`・`label`・`description` | 文字 (空にすると、項目を消します) |
| 結線 | 接続元の位置・接続先の位置 | `tm/relationships.json` の `from.position`・`to.position` | 角度 (整数に丸め、0 から 359 にそろえます) |
| 結線 | カーディナリティ | `tm/relationships.json` の `from.cardinality`・`to.cardinality` | `1` か `3` (多)。空にすると項目を消し、記号を描きません |
| 結線 | オプショナリティ | `tm/relationships.json` の `from.optionality`・`to.optionality` | `0` (任意。○) か `1` (必須。横棒)。空にすると項目を消し、記号を描きません |
| 結線 | サブセットの区分・区分コード | `tm/relationships.json` の `subset.kind`・`subset.code` | 区分は `same` (=) か `different` (×)。区分コードを空にすると、`subset` ごと消します。区分だけで区分コードの無い `subset` は作れません |

- 識別子・属性の行を右クリックしたときに出るのは、その行が参照しているマスタです。
同じマスタを参照しているほかのエンティティの行にも、変更が反映されます。
行そのもの (エンティティに持たせる識別子・属性の追加・削除・名前の上書き) は、`data/` の JSON で変えます。
- 結線は、線をクリックして開きます。
接続元・接続先のエンティティと、垂下する表 (`mapping.entity`) は見るだけです。(`data/` の JSON で変えます)
- 接続位置の角度は、エンティティの中心から見た向きです。
0 が真下で、時計回りに 90 が左、180 が真上、270 が右です。
- 幅 (`size.w`) と高さ (`size.h`) は、d3.ter が内容に合わせて決めるため、いまは図に反映されません。
- 値がおかしいとき (数でない、幅や高さが 0 より小さい、種別が 10 種のどれでもない、カーディナリティやオプショナリティが候補のどれでもない、名称が空) や、保存できなかったときは、図の上にエラーを表示します。

## 画面遷移図で名称・URL・色を変える

画面遷移図のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/sitemap/` に保存して、図を描き直します。
項目の一覧と、入れられる値の検査は、@yanqirenshi/model.sitemap (画面遷移図の図ごとの知識をまとめたパッケージ) が決めます。
枠線・背景・線の既定の値も、model.sitemap のものです。(d3.sitemap も同じものを読みます)

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| ノード | 名称 | `sitemap/nodes.json` の `label.contents` | 文字 (空にはできません) |
| ノード | 種類 | `sitemap/nodes.json` の `node_type` | 文字 (空にすると、項目を消します) |
| ノード | URL | `sitemap/nodes.json` の `link.url` | 文字 (空にすると、`link` ごと消して、リンクのアイコンを消します) |
| ノード | 幅・高さ | `sitemap/nodes.json` の `size.w`・`size.h` | 0 以上の数 (整数に丸めます。0 で子に合わせます) |
| ノード | 背景色 | `sitemap/nodes.json` の `background.color` | 色 (`#ff0000`・`red`・`rgb(255, 0, 0)` など) |
| ノード | 枠線の色 | `sitemap/nodes.json` の `border.color` | 色 (背景色と同じ) |
| ノード | 枠線の太さ | `sitemap/nodes.json` の `border.width` | 0 以上の数 |

- 背景色・枠線は、データに書いていないときも、図に描いている値 (既定の値) を出します。
保存するのは、変えた項目だけです。
- 線 (遷移) は、d3.sitemap にクリックの通知が無いので、インスペクタを開けません。(`data/` の JSON で変えます)
- リンクのアイコン (`link.icon`)・URL パス (`path`)・ラベルの文字の大きさや色 (`label.font`) は、`data/` の JSON で変えます。
- 子のノード (`children` の中のノード) も、同じように変えられます。
- 値がおかしいとき (数でない、幅や高さが 0 より小さい、色として読めない、枠線の太さが 0 より小さい、名称が空) や、保存できなかったときは、図の上にエラーを表示します。

## システム構成図で名称・種類・色・矢印を変える

システム構成図のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/deployment/` に保存して、図を描き直します。
項目の一覧と、入れられる値の検査は、@yanqirenshi/model.deployment (システム構成図の図ごとの知識をまとめたパッケージ) が決めます。
枠線・背景・線・矢印・角度の既定の値も、model.deployment のものです。(d3.deployment も同じものを読みます)

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| ノード | 名称 | `deployment/nodes.json` の `label.text` | 文字 (空にはできません) |
| ノード | 種類 | `deployment/nodes.json` の `type` | `NODE`・`COMPONENT` |
| ノード | 説明 | `deployment/nodes.json` の `description` | 文字 (ツールチップに出ます。空にすると、項目を消します) |
| ノード | URL | `deployment/nodes.json` の `link.url` | 文字 (空にすると、`link` ごと消して、左下の「link」を消します) |
| ノード | 幅・高さ | `deployment/nodes.json` の `size.w`・`size.h` | 0 以上の数 (整数に丸めます。0 で子に合わせます) |
| ノード | 背景色 | `deployment/nodes.json` の `background.color` | 色 (`#ff0000`・`red`・`rgb(255, 0, 0)` など) |
| ノード | 枠線の色 | `deployment/nodes.json` の `border.color` | 色 (背景色と同じ) |
| ノード | 枠線の太さ | `deployment/nodes.json` の `border.width` | 0 より大きい数 |
| 線 | 接続元の位置・接続先の位置 | `deployment/edges.json` の `from.position`・`to.position` | 角度 (整数に丸め、0 から 359 にそろえます) |
| 線 | 線の色 | `deployment/edges.json` の `stroke.color` | 色 (背景色と同じ) |
| 線 | 線の太さ | `deployment/edges.json` の `stroke.width` | 0 より大きい数 |
| 線 | 終点の矢印 | `deployment/edges.json` の `stroke.marker.end` | `true`・`false` |

- 背景色・枠線・線の色・線の太さ・矢印は、データに書いていないときも、図に描いている値 (既定の値) を出します。
保存するのは、変えた項目だけです。
- 接続位置の角度は、ノードの中心から見た向きです。
0 が真下で、時計回りに 90 が左、180 が真上、270 が右です。
- 始点の矢印は d3.deployment が描かないので、項目にありません。
終点の矢印を変えると、`stroke.marker` は始点側も含めて書き込まれます。(d3.deployment が `marker` を丸ごと置き換えるため)
- ラベルの位置や文字の大きさ・色 (`label.position`・`label.font`)・余白 (`padding`) は、`data/` の JSON で変えます。
- 子のノード (`children` の中のノード) も、同じように変えられます。
- 値がおかしいとき (数でない、幅や高さが 0 より小さい、色として読めない、種類が 2 つのどちらでもない、枠線や線の太さが 0 以下、矢印が `true` / `false` でない、名称が空) や、保存できなかったときは、図の上にエラーを表示します。

## Overview でサイズ・色・接続位置・ラベルを変える

Overview のインスペクタでは、次の項目を書き換えられます。
値を変えて「適用」を押すと、`data/overview/` に保存して、図に反映します。
項目の一覧と、入れられる値の検査は、@yanqirenshi/model.unchi (d3.unchi の図ごとの知識をまとめたパッケージ) が決めます。

| 要素 | 項目 | 保存先 | 入れられる値 |
|---|---|---|---|
| ノード | 名称 | `overview/nodes.json` の `label.text` | 文字 (空にはできません) |
| ノード | 幅・高さ | `overview/nodes.json` の `size.w`・`size.h` | 1 以上の数 (整数に丸めます) |
| ノード | 背景色 | `overview/nodes.json` の `background.color` | 色 (`#ff0000`・`red`・`rgb(255, 0, 0)` など) |
| ノード | 枠線の種類 | `overview/nodes.json` の `border.type` | `solid` (実線)・`dashed` (破線)・`dotted` (点線) |
| ノード | 枠線の色 | `overview/nodes.json` の `border.color` | 色 (背景色と同じ) |
| ノード | 枠線の太さ | `overview/nodes.json` の `border.width` | 0 より大きい数 |
| 線 | 接続元の位置・接続先の位置 | `overview/edges.json` の `from.position`・`to.position` | 角度 (整数に丸め、0 から 359 にそろえます) |
| 線 | 始点のマーカー・終点のマーカー | `overview/edges.json` の `from_marker`・`to_marker` | `none`・`arrow`・`triangle`・`triangle-open`・`circle`・`circle-open`・`diamond`・`diamond-open` |
| 線 | 線の色 | `overview/edges.json` の `stroke.color` | 色 (背景色と同じ) |
| 線 | 線の太さ | `overview/edges.json` の `stroke.width` | 0 より大きい数 |
| 線 | ラベル | `overview/edges.json` の `label.text` | 文字 (空にすると、ラベルを消します) |

- 背景色・枠線・線の色・線の太さは、データに書いていないときも、図に描いている値 (既定の値) を出します。
保存するのは、変えた項目だけです。
- 線のラベルは、線の真ん中に描きます。
名称やラベルの文字の大きさや色 (`label.font`) は、`data/` の JSON で変えます。
- 文字だけのノード (`type` が `TEXT`) の本文は `text` に書くので、ここでは変えられません。
(`data/` の JSON で変えます)
- 接続位置の角度は、ノードの中心から見た向きです。
0 が真下で、時計回りに 90 が左、180 が真上、270 が右です。
- ノードの項目と、線の色・線の太さ・マーカーを変えたときは、図を描き直します。
このときも、図全体の表示の位置や拡大の度合いは、そのままにします。
- 接続位置とラベルだけを変えたときは、描き直さずに線だけを動かします。
- 子のノード (`children` の中のノード) も、同じように変えられます。
- 値がおかしいとき (数でない、幅や高さが 1 より小さい、色として読めない、枠線の種類が 3 つのどれでもない、マーカーが一覧のどれでもない、枠線や線の太さが 0 以下、ノードの名称が空) や、保存できなかったときは、図の上にエラーを表示します。

## 位置の保存のきまり

- 位置は、整数に丸めて保存します。
- 図全体を動かしたり、拡大・縮小したりする操作は、保存しません。
- 保存できなかったときは、図の上にエラーを表示します。(API サーバーが止まっているときなど)

## 入れ子のノード (システム構成図・Overview)

システム構成図と Overview のノードは、`children` で入れ子にできます。

- 親のノードを動かすと、子のノードも一緒に動きます。
保存されるのは親の位置だけで、子の位置 (親の中での位置) は変わりません。
- 子のノードだけを動かすと、子の位置 (親の中での位置) が保存されます。

## ノードのリンク (システム構成図)

システム構成図のノードには、`link` でリンクを付けられます。
ノードの左下に「link」と出て、押すと `url` を新しいタブで開きます。
ノードに当たるフォルダ (Box や GitHub など) を開けるようにするときに使います。
`url` は、インスペクタの「URL」からも変えられます。

```json
{
    "id": 4,
    "type": "COMPONENT",
    "label": { "text": "COMP 01" },
    "size": { "w": 200, "h": 100 },
    "position": { "x": 50, "y": 50 },
    "link": { "url": "https://example.com/" },
    "children": []
}
```

## Overview のデータ

Overview は、@yanqirenshi/d3.unchi で描くポンチ絵 (なんでもありの概念図) です。
`overview/nodes.json` と `overview/edges.json` には、d3.unchi の入力データの形のまま書けます。
(文字だけのノード・矢羽・円筒・画像など。書き方は d3.unchi の README を見てください)

- スキーマで検査するのは、`id`・`type`・`_class`・`size`・`position`・`children` と、線の端点・マーカーです。
見た目の項目 (`label`・`border`・`background` など) は検査しません。
- `id` には、数のほかに文字列も使えます。
子のノードも含めて、ほかのノードと重ならないようにします。

## ほかで変わったとき

ほかのタブ・エディタ・git でデータが変わったときは、図を描き直します。
このとき、図全体の表示の位置や拡大の度合いは、初めの状態に戻ります。
自分のドラッグで保存したときは、描き直しません。

## ノードや線を増やすとき

画面からできるのは、位置の変更と、ER 図の名前・コード・説明・幅・高さ・データ型の変更と、TM の名前・種別・説明・幅・高さ・結線の記号 (角度・カーディナリティ・オプショナリティ・サブセット) の変更と、画面遷移図の名称・種類・URL・幅・高さ・色・枠線の変更と、システム構成図の名称・種類・説明・URL・幅・高さ・色・枠線・線の角度・色・太さ・矢印の変更と、Overview のサイズ・色・枠線・接続位置・名称・ラベルの変更だけです。
ノード・線・カラムなどを増やすときは、`data/` の JSON を書き換えます。
書き換えると、開いている画面にすぐ反映されます。
書き方は、[データの管理](#/data) と、`server/schemas/` のスキーマを見てください。
